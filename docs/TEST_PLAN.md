# TEST PLAN — перевірка готовності MVP

## 1. Автоматизовані тести (в комплекті), входять у CI

```bash
npm run test:run       # Vitest
npm run typecheck      # tsc --noEmit
npm run build          # vite build
```

Юніт-тести (`src/test/`):

- `timecode.test.ts` — формат «00:01:24» → 84; MM:SS/HH:MM:SS; дробові; негативи → null;
  нормалізація маркера (clamp 0..1); clampToDuration.
- `validations.test.ts` — валідація імені (1..60) і тексту (1..2000) з trim;
  таймкод (>= 0, <= duration+1.5); checkVideoFile (.mp4 only);
  ApiError статус/коди; buildCommentTree (1 рівень, сортування, сироти);
  countOpenComments.

CI: `.gitlab-ci.yml` запускає typecheck + test:run перед build — розрив пайпа
за флаку відмовляє в деплої.

⚠️ Згідно з ТЗ тези («не писати, що тести пройшли, якщо не запускалися»):
на момент коміту всі ці команди виконано у робочій копії, 21/21 тестів green.
Рекомендовано запускати і на вашій машині.

## 3. Інтеграційний сценарій «руками» (з ТЗ, acceptance criteria)

Готуємо: локально `.env.local` + міграції + адмін за кроками SETUP.md,
або спочатку у mock-режимі (шляхи і будуть ті самі).

- [ ] «npm install && npm run dev» стартує сайт (`/login`).
- [ ] Адмін входить; гость (інкогніто) не бачить адмінських даних (RLS/токен guard).
- [ ] Адмін створює проєкт `Demo`, завантажує v1 (H.264/AAC MP4), бачить «чернетка».
- [ ] До публікації глядач за посиланням бачить «Відео ще не опубліковано».
- [ ] Публікація v1 → глядач дивиться ролик: play/pause, перемотка, гучність, швидкість 0.5–2×.
- [ ] Гость коментує: «Зроби перехід плавнішим» на 00:00:12; коментар бачно після F5;
      клік по таймкоду переносить плеєр на 12-ту секунду.
- [ ] Адмін бачить коментар, відповідає, позначає «Виконано», потім «Відкрити».
- [ ] Адмін додає v2 (чернетка): гость як і раніше дивиться v1.
- [ ] Публікація v2 → той самий URL для гостя відкриє v2 після перезавантаження.
- [ ] Коментарі v1 НЕ перемішуються з v2; адмін відкриває v1 і бачить старі.
- [ ] Поки гость дивиться v1, публікується v2 → банер «Доступна нова версія»,
      відтворення НЕ стрибає; «Оновити відео» перемикає з новими коментарями.
- [ ] Відкликання посилання → подальші виклики API падають 403; раніше видані
      signed URL діють до кінця TTL (фундаментальне обмеження).
- [ ] Підміна чужих ID гостьом (curl з вигаданим versionId) → 403/409, а не дані.
- [ ] `​<script>alert(1)</script>` у тексті коментаря рендериться як текст (React escaping).
- [ ] iPhone/Safari (MVP desktop-first, але працює): відео відкривається, seek працює,
      форма коментарів доступна.
- [ ] GitLab pipeline зелений, production URL, `/#/review/<token>` відкривається напряму.

## 4. Ручний smoke-чек браузера

- Тулбар плеєра: play/pause, seek по кліку, маркери-коментарі (клік переносить),
  гучність, швидкість, fullscreen.
- Коментування: кнопка «Залишити коментар» фіксує поточний таймкод; «Взяти поточний
  таймкод» оновлює; ручний ввід 01:24 → 84 с.
- 409 у гостя при публікації нової версії — банер із кнопкою переходу, чернетка
  тексту лишається у полі.
- Мобільна розгортка: плеєр над коментарями, адмінка — 1 збоку колонка (stack).

## 5. Границі (hard limits)

- Границі: екстремально довгі ролики (>4 год) не перевірені — фронт-валідація
  обмежена через duration tolerance (1.5 с).
- Rate limiter в Edge Functions не строгий (документовано в ARCHITECTURE §2).
