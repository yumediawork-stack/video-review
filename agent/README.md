# Локальний агент трансляції («стріам з вашого PC»)

Гість дивиться відео **прямо з вашого Mac** через публічний тунель — відео НЕ
завантажується у Supabase (БД не росте, об'єм файлу 5 ГБ — не важливий).

## Як це працює

```
DaVinci Resolve ──export──▶ папка на вашому Mac
                              │
                     agent.mjs (тут!)
                              │  HTTP Range + тунель trycloudflare.com
                              ▼
                    браузер гостя <video>
```

- Агент слідкує за папкою; як щойно файл «дописався» (стабільний ≥15 с) — він
  стає поточним.
- Supabase отримує лише метадані (ім'я, розмір, базовий URL тунеля) — новий
  файл з'являється в панелі як **чернетка-версія**; «Опублікувати цю версію» —
  вручну, як і раніше.
- Гостьовий постійний URL не змінюється. Тунель-URL змінюється між
  перезапусками агента — панель отримує новий сама; гість, що дивився,
  автоматично підхопить нову URL на наступному seek/refresh (зберігається час).

## Налаштування (один раз)

1. У панелі адміна, в розділі **«Трансляція з PC»** проєкту:
   натисніть «Активувати агент» → скопіюйте токен (показується один раз)
   і завантажте `agent.json` (там уже всі поля для цього проєкту).
2. Зберіть `agent.json` у папку агентів і запустіть:

```bash
cd "шлях/до/video-review/agent"
node agent.mjs ./agent.json "/Ваші/Відео/DaVinci Exports"
```

3. Тунель: якщо `cloudflared` не встановлений — агент сам його завантажить
   (Linux/macOS, без будь-якого акаунту). Або заздалегідь: `brew install cloudflared`.

## Що бачить гість, коли ваш комп'ютер офлайн

Акуратну плашку «Монтажер зараз офлайн» (комментарі залишаються видимими).
Вона щезає, щойно агент знову в мережі.

## Обмеження

- Гост може дивитися **лише поки агент працює** (Mac увімкнений, Resolve не
  обов'язково відкритий — важлива лише папка з файлом).
- Тунель `*.trycloudflare.com` — public; для дуже чутливих матеріалів
  рекомендовано парольний доступ (наступна іньовація) або приватний тунель
  з доменом (`cloudflared tunnel login`).
- Один агент — одна папка/файл наразі; кілька камер тут не підтримуються.
