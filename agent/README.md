# Локальний агент трансляції («стрім з вашого ПК»)

Гість дивиться відео **прямо з вашого комп'ютера** (Windows / macOS / Linux)
через публічний тунель — відео НЕ завантажується у Supabase, у БД лише URL.
Розмір файлу (>200 МБ, хоч гігабайти) не має значення.

## Як це працює

```
DaVinci Resolve ──export──▶ папка на вашому ПК
                              │
                     agent.mjs (тут!)
                              │  HTTP Range + тунель trycloudflare.com
                              ▼
                     браузер гостя <video>
```

- Агент слідкує за папкою; якщо файл «дописався» (стабільний ≥15 с) — він
  стає поточним.
- Supabase отримує лише метадані (ім'я, розмір, базовий URL тунеля) — нова
  версія з'являється в панелі як **чернетка**; публикація — вручну, як і раніше.
- Гостьовий постійний URL не змінюється. Тунель-URL змінюється між
  перезапусками агента — адмінка отримує новий сама; гість, що дивився,
  підхоплює нову URL автоматично (плеєр зберігає позицію).

## Налаштування (один раз)

1. У панелі адміна, розділ **«Трансляція з PC»**: «Активувати агент» →
   токен показується один раз → **Завантажити agent.json**.
2. Положіть `agent.json` у теку `agent/` (поруч із `agent.mjs`) — та запустіть.

### Windows (PowerShell)

```powershell
cd C:\шлях\до\video-review\agent
node agent.mjs .\agent.json "D:\Resolve Exports"
```

> Потрібен Node.js 20+: https://nodejs.org (LTS). `cloudflared` агент сам
> завантажує в `agent\.bin\cloudflared.exe` — встановлювати нічого не треба.
> За бажанням: `winget install Cloudflare.cloudflared`.

### macOS / Linux

```bash
cd шлях/до/video-review/agent
node agent.mjs ./agent.json "/Users/ім'я/Movies/DaVinci Exports"
```

> macOS: `brew install cloudflared` — опційно (агент сам скачає бінарник).

## Що бачить гість, коли ваш комп'ютер офлайн

Акуратна плашка «Монтажер зараз офлайн» (комментарі лишаються видимими).
Зникає, щойно агент знову в мережі.

## Обмеження

- Гост може дивитися **лroke** поки агент працює (комп'ютер увімкнений;
  Resolve відкривати не обов'язково — важлива лише папка з файлом).
- Тунель `*.trycloudflare.com` — пам'ятайте про чутливі матеріали: для них
  краще налаштуваний tunnel з власним доменом (потрібен.account Cloudflare).
- Один агент — одна папка/поточний файл (кілька паралельних папок не
  підтримуються в MVP).
