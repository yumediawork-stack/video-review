# Локальний агент трансляції («стрім з вашого ПК»)

Гість дивиться відео **прямо з вашого комп'ютера** (Windows / macOS / Linux)
через публічний тунель — відео НЕ завантажується у Supabase, у БД лише URL.
Розмір файлу (>200 МБ, хоч гігабайти) не має значення.

## Підключення з веб-інтерфейсу ( Один копію-паст )

1. Адмінка → ваш проєкт → розділ **«Трансляція з PC»** → «Скопіювати команду» (WindowsBlock).
2. На ПК монтажера: вставити команду у **PowerShell** → Enter.
   Скрипт сам:
   - перевірить Node.js 20+ (якщо нема — покаже посилання nodejs.org);
   - скачає агент у `~\.video-review-agent\`;
   - активує тунель і статус «онлайн» в адмінці;
   - створить на робочому столі ярлик **«Video Review Agent»** —
     наступні запуски ДВОЙНИМи клацанням (конфіг агент зберігає localно).

> Токен вписано в команду (показується один раз). Втратили — «Активувати
> агент» знову у веб-інтерфейсі: генерується новий, старий анулюється.

## Ежедень робочий цикл

1. З Resolve експортуйте MP4 (1080p, H.264/AAC, 8–12 Mbps) у теку, яку
   стежить агент (напр. `D:\Resolve Exports`).
2. Агент побачить стабільний файл ≥15 с → створить **чернетку-версію**
   (веб-панель: «Чернетка»).
3. Переглянути плеєром, якщо треба → «Опублікувати цю версію» → гість бачить
   v2 за постійним посиланням.

## Drift це всередині

```
DaVinci Resolve ──export──▶ D:\Resolve Exports
                                │
                       agent.mjs (тут)
                                │
             HTTP Range (206) + тунель trycloudflare.com
                                ▼
                     браузер гостя <video>
```

- Ключове: гість не «слухає鸡» стрім у реальному часі — файл віддається
  з вашим темпом перемотки (seek по Range-запитах).
- Офлайн-стан: агент зупинили → гість бачить «Монтажер зараз офлайн»,
  коментарі доступны.
- Безпека: агент-токен в БД лише хешем (аналог гостьових токенів);
  revoke = агент в трафі помилку одразу.

## Manualний запуск (якщо не з браузера)

```powershell
# Windows (PowerShell), агент у ~\.video-review-agent\ або у repo
node agent.mjs --api "https://<PROJECT_REF>.supabase.co" --token "<ТОКЕН>" --watch "D:\Resolve Exports"
node agent.mjs                # наступні запуски (конфіг збережено поруч)
```

```bash
# macOS / Linux
node agent.mjs --api "https://<PROJECT_REF>.supabase.co" --token "<ТОКЕН>" --watch "~/Movies/DaVinci Exports"
```

## Файли

- `agent.mjs` — сам агент (HTTP Range + тунель + announce). Залежностей нема.
- `agent-boot.ps1` / `agent-boot.sh` — підключення з веб-інтерфейсу.
- `agent.json` — створюється агентом після bootstrap (не відслідковується git).

## Обмеження

- Гость чекає лише поки агент онлайн (комп'ютер увімкнений; сам Resolve
  відкривати не обов'язково — потрібна лише тека з MP4).
- Тунель `*.trycloudflare.com` — для чутливих locale краще налаштований
  tunnel з власним доменом (акаунт Cloudflare) — могу додати.
- Один агент = одна тека/поточний файл.
